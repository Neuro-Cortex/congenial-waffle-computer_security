# Contribution guidelines

## Workflow
1. Open an issue describing the research question, change, or experiment.
2. Create a branch using `docs/`, `research/`, `experiment/`, or `fix/` prefixes.
3. Keep changes focused and cite primary sources for factual claims.
4. Do not commit model weights, restricted datasets, secrets, or private information.
5. Submit a pull request with motivation, changes, validation, and limitations.

## Research standards
- Separate hypotheses from findings.
- Include reproducibility metadata for experiments.
- Preserve raw results; do not silently overwrite or selectively omit runs.
- Ask for review before changing the evaluation protocol or held-out test set.
