# Reproducibility checklist

- [ ] Exact model checkpoint and tokenizer revision recorded
- [ ] SAE / feature dictionary identifier and hash recorded
- [ ] Dataset source, license, version, and checksum recorded
- [ ] Prompt-set split and held-out policy documented
- [ ] Code commit hash and dependency versions recorded
- [ ] Hardware, precision, and runtime settings recorded
- [ ] Random seeds recorded
- [ ] Baseline and intervention controls run
- [ ] Metrics and scoring rules defined before final evaluation
- [ ] Uncertainty and variation across seeds reported
- [ ] Negative results and protocol deviations documented
- [ ] Independent reproduction instructions tested
